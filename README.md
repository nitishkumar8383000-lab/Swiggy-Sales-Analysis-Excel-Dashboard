# Swiggy-Sales-Analysis-Excel-Dashboard
📊 Project Overview

This project presents an interactive Swiggy Sales Analysis Dashboard created using Microsoft Excel. It provides a clear overview of sales performance, customer ratings, orders, food types, and geographic performance.
